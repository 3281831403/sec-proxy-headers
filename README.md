反向代理后面拿到的客户端地址全是内网地址，风控按这个地址全都判成了同一人：解析转发链时没有去掉空白，地址带着空格就无法匹配可信网段；取转发链最右端的地址当作客户端，拿到的其实是代理自身；无条件信任所有来源，伪造的转发头会被直接采纳；判断可信网段时用字符串前缀比较，十点零和十点零一的网段被混为一谈；不限制转发链长度，超长请求头带来解析开销和拒绝服务风险；判断协议时不看来源是否可信，明文协议可以被伪造成安全协议；清洗请求头时保留客户端自带的可信头，代理写入的值被覆盖；主机头不校验白名单，任意域名都可以进入路由；策略校验不检查是否信任任意来源；批量处理复用上一轮的解析结果，后一个请求沿用了前一个请求的转发链。engine/proxy/headers.py 是核心，tests/proxy/test_headers.py 15个红。要修的是：按上面的顺序把 10 个缺陷逐个修掉。
